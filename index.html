소리 = 공기의 진동

  • 소리는 공기 압력의 변화가 전달되는 파동.
  • 마이크는 이 압력 변화를 전기 신호로 변환.
  • 컴퓨터는 소리를 시간에 따른 진폭 변화, 즉 파형으로 저장.
주기와 주파수
\( f = 1 / T \)
예: 한 주기가 0.01초이면 \( f = 100\,\text{Hz} \)
사인파 한 주기 — 가로: 시간, 세로: 진폭

인간 음성 = 성대 진동 + 성도 공명

단계설명
성대공기를 주기적으로 끊어 기본 진동 생성
성도입·혀·입술·목구멍이 특정 주파수를 강조
음원–필터 이론
성대가 소리의 원천(source)을 만들고 성도가 이를 거르는 필터(filter) 역할을 함.
TTS 출력도 결국 파형이므로 source–filter 관점에서 인간 음성과 동일 기준으로 분석 가능.

VOT: 자음이 터지고 성대가 울리기까지의 시간

VOT = 파열이 터지는 순간과 뒤따르는 모음에서 성대 진동이 시작되는 순간 사이의 시간.
\[ \text{VOT} = t_{\text{성대 진동 시작}} - t_{\text{파열 개방}} \]
  • 예: 파열 개방 0.520초, 성대 진동 시작 0.565초
    → 0.045초 = 45 ms
  • 참고 범위:
    경음 10–20 ms · 평음 30–50 ms · 격음 70 ms 이상
Praat 측정 절차
  1. 파형에서 버스트(파열) 지점 선택
  2. 성대 진동 시작 지점 선택
  3. 두 시간값의 차이를 기록

TTS의 음성 합성 방식과 특성

TTS는 텍스트를 곧바로 소리로 바꾸지 않고 중간 음향 표현을 거쳐 음성 파형을 생성.
출력이 인간 음성과 동일한 물리적 파형이므로 동일한 음향 도구로의 비교가 가능.

방식 원리 특성
연결 합성 녹음된 실제 음성 조각을 이어 붙임 조각 음질은 깨끗하나 연결부·억양이 부자연스러움
통계적 파라미터 합성 음성 특징을 통계 모델로 예측 부드럽게 이어지나 전반적으로 뭉개지고 둔탁함
신경망 합성
(현재 주류)		 딥러닝으로 텍스트에서 음향 표현 예측 자연성 높음. 학습 데이터의 발음 경향·편향을 반영
분석 대상

문장 자연성의 문제

  • 짧은 단어에서는 VOT, \(f_0\), 포먼트가 중요.
  • 실제 음성의 자연성은 문장 단위의 휴지·억양·정보구조와도 관련.
  • 한국어 TTS 연구에서는 휴지 오류가 발화 해석과 품질에 영향을 준다고 보고됨.
확장 방향
  • 문장 단위 pitch contour 비교
  • 운율 경계·휴지 위치 분석
  • MOS(Mean Opinion Score) 청취 평가와 음향 지표 상관 분석

결론 20 / 21

AI 음성의 자연성은 물리적 신호 재현의 문제

결과 요약
  • 파열음에서 TTS는 \(f_0\)는 인간과 유사하게 재현했으나, VOT에서 격음은 인간보다 짧게 구현함.
  • 모음에서 TTS는 인간보다 모음 공간이 좁았고, ㅐ/ㅔ는 거의 완전히 합류했으며 오/우도 가깝게 나타남.
결론
  • TTS는 한국어의 음향 단서를 인간과 다른 비중으로 재현. 어색함의 원인일 수 있음.
  • TTS 발음에서 나타나는 특성(VOT보다 \(f_0\)에 의존, ㅐ/ㅔ 발음 합류)는 TTS가 현대 한국어의 변화를 학습한 것으로 보임.
한계
  • 실험에 사용된 표본이 매우 적기 때문에 하나의 사례로 보는 것이 적절함.
  • spectral tilt, jitter·shimmer 같은 미세 음향 특성의 정량 분석, 문장 단위 운율(휴지·억양) 비교는 후속 과제임.
