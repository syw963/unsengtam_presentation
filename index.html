음원-필터 이론: 소스

성대 진동이 만드는 배음 스펙트럼

음원 (Source)
  • 성대가 주기적으로 열고 닫히며 기본 주파수 F₀를 생성
  • 동시에 F₀의 정수배인 배음(harmonics)을 함께 방사
  • 성문 소스 스펙트럼: 고주파로 갈수록 진폭 감소 (약 −12 dB/oct)
  • 이 단계에서는 모음 구별 없음 — 모든 모음의 소스는 같은 구조
성문 소스 스펙트럼
F₀, 2F₀, 3F₀, … 각각의 배음은 존재하나, 어떤 배음이 증폭되는지는 성도(필터)가 결정
/u/ 소스 스펙트럼 — 각 막대가 배음 성분, 고주파로 갈수록 진폭 감소

음원-필터 이론: 필터

성도 공명이 특정 배음을 증폭 → 포먼트

필터 (Filter)
  • 음원이 성도(vocal tract)를 통과하면서 공명 주파수 대역의 배음이 선택적으로 증폭
  • 증폭된 주파수 봉우리를 포먼트(formant)라 부름
  • 모음의 음색은 주로 F1(제1포먼트)과 F2(제2포먼트)가 결정
핵심 원리
소스(배음 구조)는 고정, 필터(성도 형태)만 바뀐다
→ 성도 형태 = 모음 음색을 결정하는 변수

반폐쇄관 공명 모델

성도를 균일 반폐쇄관으로 근사하면 공명 주파수를 예측할 수 있다

모델 설정
  • 성대 쪽(성문): 닫힌 끝 → 압력 배(antinode)
  • 입술 쪽: 열린 끝 → 압력 절(node)
  • 이 반폐쇄관(closed-open tube)의 공명 조건:
공명 주파수
\[ f_n = \frac{(2n-1)\,c}{4L} \quad n = 1, 2, 3, \ldots \]
L ≈ 17.5 cm, c = 340 m/s 대입 시
F1 ≈ 486 Hz, F2 ≈ 1457 Hz, F3 ≈ 2429 Hz
(중립 모음 /ə/의 실측값과 일치)
이 모델의 한계
균일관 → 혀 움직임의 효과를 설명 못함. 다음 슬라이드의 섭동 이론과 두 공명기 모델로 보완
성도 내 R1~R4 정상파 분포 — 왼쪽이 성문(닫힌 끝), 오른쪽이 입술(열린 끝)

섭동 이론: 협착 위치가 포먼트를 정한다

Stevens (1989): 협착이 정상파의 어느 점에 놓이느냐가 포먼트 방향을 결정

섭동 규칙
협착이 속도 배(velocity antinode)에 → 그 포먼트 하강  |  협착이 속도 절(velocity node = 압력 배)에 → 그 포먼트 상승
F1 속도 정상파 \(\sin(\pi x / 2L)\) — 성문(왼쪽)이 속도 절, 입술(오른쪽)이 속도 배. 협착 위치(빨간·파란 점)에 따른 F1 방향 변화
고모음 /i/, /u/ — F1 낮음
협착이 입 쪽(속도 배 근처) → F1 하강
→ 예측: 고모음 F1 ≈ 200–400 Hz ✓
저모음 /a/ — F1 높음
협착이 인두(속도 절 근처) → F1 상승
→ 예측: 저모음 F1 ≈ 700–900 Hz ✓
ㅔ/ㅐ — 협착 위치 동일
두 모음의 혀 위치가 매우 유사
→ 포먼트 섭동 방향이 같음 → 합류의 물리적 근거

두 공명기 모델: 정량적 뒷받침

Fant (1960): 혀의 협착으로 성도가 두 관(공동)으로 분할됨

  • 협착 → 뒤쪽 공동(인두, L₁)과 앞쪽 공동(구강, L₂)으로 분리
  • 각 공동은 근사적 1/4파장 공명기: \(f \approx c/4L\)
  • 공동이 길수록 공명 주파수가 낮다
계산 예 (Fant 1960)
/i/ (전설고모음): L₁≈9cm → F1≈190Hz(낮음), L₂≈8cm → F2≈2100Hz(높음)

/a/ (후설저모음): L₁≈8cm → F1≈940Hz(높음), L₂≈9cm → F2≈940Hz(낮음)
주의사항
어느 공동이 F1·F2를 맡는지는 협착 위치에 따라 뒤바뀜. 단순 'V₁=F1' 대응은 근사일 뿐 — 1차 설명은 섭동 이론
성도 단면 두 공동 모델 — V₁(인두), V₂(구강), D₁·D₂는 협착 부위의 직경

달팽이관의 주파수 분석

기저막의 tonotopy — 위치에 따라 처리하는 주파수가 다르다

기저막 tonotopy
  • 기저(base)는 고주파(20kHz), 첨부(apex)는 저주파(20Hz) 처리
  • 모음 포먼트 대역(200~2500Hz)은 기저막 첨부 쪽에 집중
  • 주파수가 비슷한 두 소리는 기저막의 인접한 위치를 자극 → 구별이 어려워짐
결정적 문제
기저막의 주파수 분해능에는 근본적인 한계(임계대역)가 있다. F1이 10Hz 차이나는 ㅔ/ㅐ는 이 한계 안에 드는가?
F1 영역
ㅔ/ㅐ의 F1 ≈ 535–545Hz → 기저막 첨부 쪽, 물리적으로 가장 조밀한 영역
달팽이관 기저막 tonotopy — 위치별 반응 주파수 분포 (base=고주파, apex=저주파)

임계대역 (Critical Band)

Moore & Glasberg (1983): ERB — 기저막의 주파수 분해능 상한

  • 두 주파수가 같은 임계대역(critical band) 안에 들면 변별 단서가 약해짐
  • ERB 공식 (Equivalent Rectangular Bandwidth):
Moore & Glasberg 1983
\[\text{ERB}(f) = 24.7 \times \!\left(\frac{4.37f}{1000} + 1\right)\]
단위: Hz  ·  f는 중심 주파수(Hz)
ㅔ/ㅐ 임계대역 계산
F1 ≈ 540 Hz에서:
ERB(540) = 24.7 × (4.37×0.540 + 1) ≈ 83 Hz

ㅔ/ㅐ F1 차이: 10 Hz
→ 10 Hz << 83 Hz → 같은 임계대역 내
기저막 거리 환산
10Hz 차이 → 기저막 위 약 0.09 mm — 청각 신경 해상도 이하
ERB 임계대역폭 곡선 — 주황 수직선이 ㅔ/ㅐ의 F1(≈540Hz), 음영이 해당 임계대역

단모음화가 합류의 구조적 전제 조건을 만들었다

반론 검토: 인접성은 충분조건인가?

음향 공간에서 인접한데도 합류하지 않는 모음 쌍이 존재한다

예상 반론
ㅗ/ㅜ, ㅓ/ㅗ도 F1-F2 공간에서 상대적으로 인접하나 현재까지 합류하지 않았다. 그렇다면 음향적 인접성은 합류의 충분조건이 아니다 — 필요조건에 불과하다.
답변 1 — 논제는 이미 이를 인정
논제: "인접한 모음은 합류하기 쉽고, 먼 모음은 합류하지 않는다" → 확률·취약성의 주장이지 필연성 주장 아님
답변 2 — 기능부담량이 차이를 만든다
ㅗ/ㅜ는 ㅔ/ㅐ보다 기능부담량이 훨씬 높음 → 구별 소실의 의사소통 손실이 커서 합류 압력이 약함 (다음 슬라이드)
결론: 이중 조건 모델
합류 실현 = 물리적 취약성(음향 인접 + 청각 한계) AND 낮은 기능부담량(사회언어학적 허용). 두 조건의 결합이 ㅔ/ㅐ를 특별히 취약하게 만든다.

물리적 설명의 범위

음향·청각 모델이 설명하는 것과 설명하지 못하는 것

설명 가능 ✓
· 왜 ㅔ/ㅐ가 합류 취약한가
· 왜 ㅏ·ㅣ·ㅜ는 합류하지 않는가
· 왜 단모음화 이후 합류 가능성이 생겼는가
· 지각적 구별 불능의 정량적 근거(ERB)
설명 불가 ✗
· 왜 하필 20세기 후반부터 가속됐는가
· 어떤 사회집단이 합류를 주도했는가
· 왜 같은 조건인 ㅗ/ㅜ는 아직 합류 안 했는가
· 변화의 시작과 확산 메커니즘
통합적 설명 모델
음향·청각 물리학은 합류의 가능성(필요조건, 취약성)을 설명한다. 실제 합류의 진행 시점과 속도는 사회언어학·기능부담량의 영역. 두 설명이 상호 보완적이며 어느 하나만으로 완전하지 않다.
변화의 "방아쇠"는 사회언어학적·기능적 요인의 영역 — 물리 모델은 어떤 방향의 변화가 가능한지 제약할 뿐

기능부담량 (Functional Load)

두 음소가 구별하는 단어 쌍의 비중 — 낮을수록 구별 소실의 의사소통 손실이 작다

정의
기능부담량(functional load): 두 음소 쌍이 어휘 구별에 기여하는 정도. King(1967)의 정보-이론적 척도 사용.

결론

음운 변화는 물리 법칙이 규정한 제약 안에서 일어난다

논제 재확인
모음의 음운 변화는 임의의 방향으로 일어나지 않는다. 음향 공간의 구조가 어떤 합류는 거의 필연적으로, 어떤 합류는 불가능하게 만든다.
핵심 발견 1
ㅔ/ㅐ는 F1-F2 공간에서 사실상 동일 좌표(F1差 10Hz) → 음향 공간 인접
핵심 발견 2
10Hz 차이는 임계대역폭(~83Hz)보다 훨씬 작음 → 달팽이관이 구별 불가
핵심 발견 3
기능부담량 0.0082(최하위권) → 합류의 의사소통 비용이 낮아 사회언어학적 촉진
음운 변화의 물리적 제약 모델
① 성도 공명 → F1·F2 좌표 확정
② 음향 인접 → 물리적 취약성
③ 임계대역 이내 → 지각 한계
④ 낮은 기능부담량 → 사회언어학적 방아쇠
⟹ 합류 실현
ㅏ·ㅣ·ㅜ는 음향 거리 최대 → ① 단계에서 차단 → 합류 없음 ✓
